# 1.0.15 release notes

Side chat can now edit completed prompts and regenerate answers. Each action creates a new temporary side chat, copies the earlier questions and answers, and submits the revised or original prompt. The original conversation stays available for comparison. This fixes the previous action-failed notification.

The current prompt retains its native attachments, and images in earlier exchanges are copied. The new chat is based on existing questions and answers; it does not copy or rerun earlier tool executions. Side chats remain temporary, so save anything you need to keep separately.

This release also includes compact message navigation. Markers retain their lengths with less empty space at the left edge, stay clear of the text when expanded, and follow the text column in wider windows. Hover previews and click-to-jump remain available.

Save unsent text and any temporary side-chat content you need, quit the app, extract the ZIP, and run **Install-Repair.cmd**. Supports Windows x64, Microsoft Store package **26.901.6511.0**, app version **26.901.51231**.
