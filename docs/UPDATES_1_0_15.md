# 1.0.15 更新说明

侧边聊天现在可以编辑已完成的问题，或重新生成回答。操作会新建临时侧聊，接入该位置之前的问答，再发送修改后的问题或原问题；原对话保留，方便比较。修复了此前点击后提示“操作未完成”的问题。

当前问题的原生附件会保留，此前问答中的图片也会复制。新侧聊基于已有问答创建，不复制旧的工具执行过程；不会重做旧工具操作。侧边聊天仍是临时会话，需要长期保留的内容请另行保存。

同时包含更紧凑的消息导航：保留刻度长度，减少左侧留白；长短刻度与正文保持间隔，宽窗口中导航跟随正文位置。悬停预览和点击跳转保持可用。

保存未发送的内容及需要保留的临时侧聊，退出客户端，解压后运行 **安装修复.cmd** 即可升级。仍支持 Windows x64，微软商店包 **26.901.6511.0**、界面版本 **26.901.51231**。
