从 `openai/codex` 按创建时间检索并阅读了最近 35 条包含 desktop 的未关闭报告。修复项目自身的 issue 列表当时为空。这里区分本地已验证的修复与尚未证实的问题，避免把版本适配等同于修复所有上游报告。

| 官方报告 | 核对结果 |
| --- | --- |

| [#46156：Chat 无法选择本地项目](https://github.com/openai/codex/issues/46156) | 涉及普通 Chat 与本地 Work 的项目能力区别。保留现有能力与权限检查，不通过简单显示选项声称获得本地文件访问能力。 |

| [#46078：超大历史导致重启](https://github.com/openai/codex/issues/46078)、[#46076：打开 Git 仓库冻结](https://github.com/openai/codex/issues/46076) | 缺少可重复的本地样本与完整根因。保留原有读取、缓存和布局优化，不删除历史、不改动仓库元数据。 |
