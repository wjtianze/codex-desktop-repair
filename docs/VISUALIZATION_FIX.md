# 互动演示兼容修复

当前版本：1.0.5。日期：2026-09-08。

部分网页演示使用桌面端缺失的样式，导致页签隐藏失效、双栏变为上下堆叠、间距和公式显示异常。兼容处理在原生演示沙箱接收 HTML 前补齐这些规则。

- 支持常用布局、间距、字体与演示颜色变量，包括不等比例网格列和相邻内容间距。
- md 双栏布局在演示宽度达到 560 像素时展开，适配桌面对话区；其他断点保留原值，较窄窗口仍使用单列。
- 多栏演示启用原生宽布局入口。演示嵌入层保持独立合成，处理滚轮滚动时画面短暂变白的反馈。
- 补充 `.hidden` 与 HTML `hidden` 规则，页签切换时只显示选中的内容。
- 用客户端已有的 KaTeX 在本机将静态文本公式转换为 MathML。保留代码、脚本、属性、SVG 文字、已排版公式和原有节点标识。
- 演示随对话整页滚动，不增加内部限高滚动条。

没有下载额外数学库、扩大沙箱能力、修改显卡设置或关闭硬件加速。生成中预览详见 [演示逐步生成](PROGRESSIVE_VISUALIZATION.md)。
