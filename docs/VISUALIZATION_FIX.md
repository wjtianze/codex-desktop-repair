# 互动演示兼容修复

发行版本：1.0.4。日期：2026-09-08。

部分在网页端生成的 HTML 演示使用旧式工具类。桌面端的基础样式没有定义这些类，导致隐藏的页签内容仍然显示，网格、间距和按钮外观也不正确。本次在原生演示沙箱接收 HTML 前补充兼容处理。

- 支持常见布局、间距、字号及演示颜色变量，保留原有响应式断点。
- 补充 `.hidden` 和 HTML `hidden` 属性的隐藏规则，脚本切换页签时只显示选中的内容。
- 使用客户端已有的 KaTeX 将静态文本公式转换为 MathML，支持普通和旧式重复转义的公式分隔符。代码、脚本、属性、SVG 文字和已排版公式不参与替换。
- 原有节点标识和更新逻辑继续生效，参数调整和预设按钮可以更新数值。
- 演示自然展开，随对话页面滚动，不增加内部限高容器。

数学排版在本机完成，不下载额外字体或数学库。兼容样式只覆盖已有演示沙箱中的内容，不修改聊天正文。没有扩大沙箱的网络范围、消息权限或其他能力。

## 验证

304 项检查通过，包含 119 项独立测试和 185 项使用官方资源的行为检查。新增检查覆盖缺失隐藏规则、响应式布局、数学分隔符、异常输入限制、原生 HTML 入口，以及 Edge 中的真实页签点击、滑块更新、脚本执行次数和节点保留。窄窗口与宽窗口均测试。

本机安装通过 28 项事务校验，37 项原有对话模型偏好全部保留。用户已确认页签和公式显示恢复；根据随后反馈移除了初版增加的内部滚动容器。去掉该容器后的真实滚动与闪动情况仍待用户确认，不能将离线布局测试当作桌面合成问题已彻底消除的证明。

## 范围

这是旧式演示的常用样式兼容层，不是完整的 Tailwind 运行时。特殊工具类及在脚本执行后才产生的公式可能仍需要演示自身处理。窄窗口下，使用 `md:grid-cols-2` 的布局仍按原设定单列显示；宽度达到断点后才显示两列。

本次没有实现生成中预览。现有客户端会隐藏尚未闭合的演示标记，完整标记仍需匹配内容引用后才能挂载演示；逐步生成需要进一步处理这条接收与渲染流程。
