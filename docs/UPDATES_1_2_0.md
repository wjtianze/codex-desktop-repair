# 1.2.0 更新说明

适配 Windows x64 官方客户端：界面版本 26.924.22138，微软商店包 26.924.2738.0，内置后端 0.158.0-alpha.2.1。

- 重新适配新版拆分后的消息、侧栏、文件引用、项目设置和可视化模块。
- 修正聊天滚动恢复、长记录渲染时的局部变量冲突及快速聊天编辑、重新生成入口。
- 保留草稿事务保存、正式侧聊历史、紧凑聊天切换、搜索来源、下载与流式可视化优化。
- 修正模型偏好目录校验、Markdown 引用缓存参数和图片引用范围。
- 稳定历史目录查询参数，避免快速聊天与侧聊挂载时反复触发目录加载。
- 新侧聊使用官方新会话标识，修正“无法加载此 ChatGPT 对话”；默认进入聊天，首次切换工作默认在云端，明确选择本地项目时进入本地工作。
- 修正启动时的屏幕接口引用、模型偏好初始化和日志写入队列。
- 安装前严格校验版本、官方签名及原始摘要，使用独立运行副本与事务备份；保留原资料目录。

新版 Owl 要求可执行文件内的归档摘要与资源一致，修补副本因此需要同步更新该摘要，其官方数字签名不再有效。微软商店原文件不受影响。

83 个套件共 528 项检查通过。自动回归与真实账户对话验收范围分别记录于 [验证说明](VALIDATION.md)，不保证所有对话或机器均消除卡顿。
