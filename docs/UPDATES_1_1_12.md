# 1.1.12：长对话渲染、教材图集与重试入口修复

适用于 Windows x64、商店包 **26.911.7940.0**，界面 **26.911.61220**。

下载 ZIP 并解压，保存未发送内容、退出客户端后运行 **安装修复.cmd**。安装保留原登录资料、对话和模型偏好，校验值见发行附件。此前公开版本 1.1.9 可直接升级。

- 修复 `api_tool` 的 `context_stuff` 教材页被误当成生成图片的问题，移除错误的空白图集；真实生成图片、用户图片、正文和文件引用继续保留。
- 上述误判也会使普通回答进入图片专用的一键重试路径。修正分类后恢复普通回答的原生重试菜单，补丁不会自动重试或重发消息。
- Chat 和 Codex 共用消息列表改为按可见高度限制屏外缓冲，避免为了预留几个回合就挂载大量长正文；保留原生可见范围、搜索跳转和显式保留的回合。
- 长消息内部按 Markdown 块跳过屏外渲染并保留测量高度，等待父级滚动容器就绪后再接入，处理新内容、宽度变化、字体加载与卸载清理。
- 缓存未变化消息的 Markdown 转换结果；临时禁止提交时保留加号按钮，原禁用、只读与权限条件继续有效。
- 再次打开同一修复版时调用原生窗口唤回机制，不再仅因同路径进程存在就报“已在运行”。

中英文两版各通过 481 项回归；真实历史重放、实际客户端页面和重试组件路径均有验证，未触发新的模型回合。特定长对话的挂载节点约减半。部分菜单首次打开仍存在约 0.1 秒级响应，网络、插件请求和模型生成速度不在这项渲染优化的保证范围内；本版本不宣称消除所有卡顿。
