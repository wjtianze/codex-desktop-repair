# 1.1.16：快速聊天模式、项目侧聊与历史保存

适用于 Windows x64，商店包 **26.911.7940.0**、界面 **26.911.61220**。保存未发送内容并退出客户端，解压发行包后运行 **安装修复.cmd**。升级保留原登录资料、对话和模型偏好；校验值见发行附件。

- 快速聊天和侧边聊天提供聊天、云端工作、本地工作。模式和运行位置控件与输入框放在一起，各模式使用独立会话标识，切换不会将本地工作上下文附到云端消息中。
- 新建本地侧聊使用原生正式会话，关闭标签不再丢弃历史或停止工作。可选择项目，也可选择“不在项目中工作”，打开对应的新侧聊；已有会话和草稿保持原位。
- 聊天和云端工作使用原生 ChatGPT 项目选择器、消息与保存流程。项目、模型和工具权限继续以账号及客户端原生检查为准。
- 修复新空白会话错误显示“未找到可显示的消息”，并让侧栏内容撑满高度，输入框贴合底部。
- 修复新版侧聊项目入口引用旧作用域与模块接口导致的加载错误。
- 快速聊天长记录接入原生可见范围渲染，保持正在更新的消息、对比结果及交互内容；测量后收缩过大的历史缓冲，避免流式更新重建未变化的消息行。

- “打开已有对话”可搜索本地工作、聊天和云端工作历史，并加载更多记录；继续原会话，不复制消息或自动发起模型回合。

此前创建的临时侧聊不会被假称为已保存；本次正式会话规则作用于新建会话。已消失的临时历史不能据此恢复。历史保存、界面加载和真实模型回复分别验证；自动检查不代表所有账号和项目的在线任务均已验收。部分菜单首次打开及长对话仍可能有短暂停顿。

此发行包仅包含修补片段、辅助代码、测试及文档，不包含官方完整程序、用户对话或账户资料。恢复方法和版本限制见 README。
