# 1.1.2：新版适配与侧聊原位更新

支持 Windows 商店包 **26.903.9818.0**、界面版本 **26.903.71938**，并验证独立 **Codex CLI 0.154.0** 与 App 自带后端 **0.153.4**。

- **侧聊编辑和重新生成留在原标签。** 后台准备好替代线程后更新当前标签，保留标签位置和标题；准备失败时不替换原对话，结果不确定时不会自动重发。
- **修复侧聊操作报错。** 历史状态改从真正的本地拥有者读取，避免把异步 RPC 代理当作同步对象，也减少不必要的跨通道历史读取。
- **侧聊可以在项目中工作。** 从工具菜单选择带工作目录的本地或远程项目，会在该目录中新建侧聊，保留当前对话，主窗口不跳转。
- **适配新的 Owl 外壳。** 保留官方可执行文件及数字签名，独立安装修补资源；旧浏览器监听补丁已撤下，沿用新版官方浏览器。
- 保留聊天位置、模型偏好、文件引用、思考摘要、快捷聊天等修复；升级与恢复包含任务栏入口，并保护中断时的恢复记录。

临时侧聊没有可直接回退的持久历史，因此原位更新会在后台重建临时线程，复制此前可见问答和附件；界面不再增加侧聊标签。它不会撤销工作目录中已经发生的文件改动。

保存未发送内容并退出 App 后运行 **安装修复.cmd**。安装不会替换独立 CLI，登录和聊天资料沿用原目录。恢复时使用 **卸载恢复.cmd**。

两版各通过 **432 项检查**。另在真实客户端验证了连续编辑／重新生成时标签数量不变，以及项目工作目录生效、主导航不变；这些验证拦截了测试线程的最终模型发送，没有消耗真实模型回合。详见 [兼容性与验证](VALIDATION.md)。

本版修复了侧聊路径中的多余 RPC 操作；尚不能保证新版 App 的所有卡顿都已解决，仍有的限制见 [已知问题](AUDIT.md)。
