# 1.1.3：新版适配、搜索对话与侧聊修复

支持 Windows 商店包 **26.908.4834.0**、界面版本 **26.908.40834**。已验证独立 Codex CLI **0.154.0** 与 App 内置后端 **0.154.0-alpha.6.2**。

- 打开含网页搜索记录的对话时不再因组件映射错误崩溃，包含回复仍在生成的情况。
- 修复多轮侧聊编辑、重新生成失败；此前的问答会正确带入，内容仍在原标签更新。
- 修复重新打开对话总回到底部的问题，恢复各段对话的阅读位置。
- 演示文件引用的 JSON 完整、仅缺结束符时可以正常显示；截断内容和后续正文不会被误吞，文件权限仍由原生加载器检查。
- 滑块小点动画跟随屏幕刷新节奏，保留隐藏窗口暂停和减少动态效果设置。
- 更新快捷聊天、项目设置、下载及侧栏入口，保留新版原生的权限和语音活动保护。

保存未发送内容并退出客户端后，运行 **安装修复.cmd**。升级沿用原登录和聊天资料目录，不替换独立 CLI。恢复使用 **卸载恢复.cmd**。

中英文两版各通过 **439 项检查**；完整与无侧栏构建分别校验 **9,030／9,029** 个打包资源。中文版已安装并通过实际页面及模块加载检查，多轮侧聊使用真实客户端接口验证，最终模型发送被拦截。详见 [兼容性与验证](VALIDATION.md)。

后台高负载程序仍可能影响界面响应，本版不保证消除所有设备上的间歇性卡顿。
