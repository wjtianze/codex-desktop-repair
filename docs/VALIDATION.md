# 兼容性与验证

## 验证组合

| 项目 | 版本 |
| --- | --- |
| 系统 | Windows x64 |

App 和独立 CLI 使用不同的可执行文件。安装修复包不会替换独立 CLI，也不会用旧后端覆盖 App 自带后端。安装前仍校验官方签名、版本与精确文件摘要；其他 App 版本会停止安装。

## 检查范围

自动检查覆盖补丁边界、完整与无侧栏构建、原生脚本语法、草稿保存、请求调度、聊天位置、模型选择、消息与图片、文件引用、搜索过程、侧聊编辑和导航布局。

安装与恢复另检查跨版本运行副本、任务栏入口、原资料目录保留、备份完整性，以及恢复被中断后能否继续。新版浏览器已经移除旧记录文件监听器，相关旧补丁不再应用；未改动的官方浏览器程序文件仍验证摘要。

从两套实际可执行文件分别生成协议结构，并验证初始化、账号读取、模型列表和权限需求读取。协议语义参考 [OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)；版本专用接口以实际生成结构为准。本次兼容性检查未启动真实模型回合。

隔离副本的模块加载和页面启动检查，与用户资料目录下的实际安装验收分别记录。自动检查不能替代所有真实对话、设备和长时间运行场景；仍有的限制见 [已知问题](AUDIT.md)。

## 本地检查

普通使用者可运行 **检查环境.cmd**。维护者使用 Node.js 24：

~~~powershell
node tests/run.cjs
node tests/run.cjs --installed
~~~

第二条命令要求安装受支持的 Windows 官方客户端，会重新生成原生夹具并执行实际修补函数和浏览器布局测试。测试结果与构建产物只保存在忽略的 build/ 目录中，不上传账户文件、聊天数据或完整官方资源。
