隔离副本的模块加载和页面启动检查，与用户资料目录下的实际安装验收分别记录。自动检查不能替代所有真实对话、设备和长时间运行场景；仍有的限制见 [已知问题](AUDIT.md)。

## 本地检查

普通使用者可运行 **检查环境.cmd**。维护者使用 Node.js 24：

~~~powershell
node tests/run.cjs
node tests/run.cjs --installed
~~~

第二条命令要求安装受支持的 Windows 官方客户端，会重新生成原生夹具并执行实际修补函数和浏览器布局测试。测试结果与构建产物只保存在忽略的 build/ 目录中，不上传账户文件、聊天数据或完整官方资源。
