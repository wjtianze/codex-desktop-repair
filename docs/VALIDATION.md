# 兼容性与验证

## 支持范围

- Windows x64。
- 微软商店包 `OpenAI.Codex 26.901.6511.0`。
- 界面版本 `26.901.51231`。

其他版本或架构会停止安装。安装程序会检查官方签名、文件摘要和生成后的资源完整性；原商店安装保留，修复版使用独立运行副本。

## 测试覆盖

1.0.7 通过了 367 项自动检查，覆盖补丁应用、安装与恢复、草稿保存、请求调度、图片与消息显示、模型选择和部分交互行为。代码块另有浏览器布局检查，确认滚动和加入高亮后外框高度不变。

自动检查使用合成数据，不能替代所有真实对话、硬件和长时间使用场景。仍待解决的情况见 [已知问题](AUDIT.md)。

## 本地检查方法

普通使用者可双击 **检查环境.cmd**，确认当前客户端是否兼容。

维护者与贡献者可使用 Node.js 24 运行：

```powershell
node tests/run.cjs
```

安装了受支持的官方 Windows 客户端后，还可以验证实际官方资源中的修补代码：

```powershell
node tests/run.cjs --installed
node tests/code-header-layout.cjs
```

生成的测试资源和结果保存在本地 `build/`，不包含在公开发行包中。
