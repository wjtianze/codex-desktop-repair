# 1.1.0：适配新版 ChatGPT App 与 Codex CLI

升级 App 后，旧版修复包会因为版本不匹配停止安装。这一版适配 Windows 商店包 **26.903.9818.0**、界面版本 **26.903.71938**，并验证与独立 **Codex CLI 0.154.0** 的兼容性。

- 保留聊天阅读位置、模型选择、思考摘要、文件引用、快捷聊天和侧聊等已有修复，接入新版组件与状态。
- 跟随新版文件展示方式：上传资料仍显示紧凑引用，生成文件保留官方文件卡片；保存过程中显示忙碌状态。
- 适配新版 Owl 运行外壳，保留官方可执行文件及其数字签名；修复仍安装在独立运行副本中。
- 新版官方浏览器已经移除旧的记录文件监听机制，因此不再应用那部分旧补丁，也不改写共享浏览器缓存中的程序文件。
- 支持跨 App 版本的事务升级；已有任务栏入口会一并更新并保留恢复备份。恢复中途失败时，会保留当前恢复记录，方便继续完成。

## 安装与恢复

保存未发送的内容并退出 ChatGPT，解压后运行 **安装修复.cmd**。登录、聊天和模型偏好沿用原来的资料目录，工作空间中的源码和修复包不作为清理对象。

独立 CLI 不会被替换。App 自带的后端为 **0.153.4**，与独立 CLI 是两个不同的可执行文件；本版分别检查了两者的协议结构和初始化、模型列表、权限需求等接口。

需要恢复时退出修复版，运行 **卸载恢复.cmd**。官方客户端、用户资料和安装备份保留。不同的 App 版本仍会停止安装，不会跳过版本和完整性检查。

测试范围与边界见 [兼容性与验证](VALIDATION.md)。
