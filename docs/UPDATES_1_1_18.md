# 1.1.18：云端 Work 图片引用

下载本页 ZIP 并解压，保存未发送内容、退出桌面端后双击“安装修复.cmd”。安装保留现有账号、聊天及模型偏好，并生成恢复备份；“卸载恢复.cmd”可撤销安装。无需另装 Python 或 Node.js，下载校验值见附件 SHA256SUMS.txt。

生成的 PNG、JPG 或 SVG 使用 `![说明](sandbox:/...)` 引用时，正文可能只剩一个独立的 `!`，图片文件则出现在下方附件卡片中。

这次修复让生成文件识别完整的 Markdown 图片节点，并在服务端引用范围只覆盖链接或路径时扩展到完整图片语法。保留原生附件卡片、下载与权限检查，不删除正文中的普通感叹号，也不将代码块里的示例识别成附件。

兼容性仍限于 Windows x64、商店包 26.915.4065.0、界面版本 26.915.31945。此修复不增加正文内嵌图片预览功能。

232 项独立检查通过。专项验证覆盖 PNG／JPG／SVG、中文与空格路径、空图片说明、括号转义、重复引用、Unicode 位置、普通链接、代码示例、流式未完成内容，以及服务端引用和本地补全两条路径。中文版已实际安装：反馈中的云端 Work 历史对话不再显示孤立感叹号，原 PNG 附件卡片保留。其余反馈截图未逐一打开；SVG／JPG 由专项检查覆盖，未重跑全部原生检查套件。

官方升级后仍需等待对应适配。问题反馈请附官方版本、修复版本和复现步骤，不上传账号文件或私人聊天记录。详细范围见 [兼容性与验证](https://github.com/wjtianze/codex-desktop-repair/blob/v1.1.18/docs/VALIDATION.md)。
