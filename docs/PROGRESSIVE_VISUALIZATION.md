# 演示逐步生成

版本：1.0.5。日期：2026-09-08。

桌面端原先会隐藏尚未闭合的演示标记。现在收到内嵌 HTML 后，在同一个原生沙箱里逐段更新预览；完整内容通过原生内容引用校验后，再初始化正式演示并恢复交互。

正常请求生成互动演示即可。页面结构、文字和静态 SVG 会随 HTML 到达逐步出现，顶部显示生成状态。完成加载后，按钮与滑块恢复使用。已完成的演示直接打开，下载和导出保留完整源码及实际文件名。

## 实现与验证

- 支持 `visualize` 和 `genui` 中的 `app_block`，识别真正的 HTML 内容，排除图标、缩略图及其他组件；只有元数据时隐藏未完成标记。
- 生成中保持组件和原生视图标识稳定，通过现有沙箱数据通路更新。预览移除脚本及事件属性，并禁用交互。
- 完整内容经原生校验后只初始化一次；就绪即恢复交互，无需等待事件流关闭。处理取消、卸载、重试和迟到结果。
- 延续原有外部内容限制、沙箱能力与用户操作检查。没有增加内层滚动条或自动发送模型请求。
- 多栏与滚动绘制见 [演示兼容修复](VISUALIZATION_FIX.md)，联网信息见 [搜索过程显示](SEARCH_PROGRESS.md)。

中英文版分别通过 326 项检查：134 项独立检查和 192 项使用官方资源的行为检查。真实浏览器检查四次逐段更新、单个预览文档、预览脚本不运行、最终只初始化一次、按钮及源码导出。另用客户端实际 Markdown 解析器验证 genui 分片、正文、代码块、行内代码及只有元数据的边界。

本机候选版通过 28 项安装事务校验，42 项原有模型偏好全部保留。安装后，用户确认交互式演示的问题已修复。自动化流式验证使用合成数据，没有额外发送真实模型请求。

## 边界

收到 HTML 后才能预览。由末尾 JavaScript 计算或绘制的图表在正式初始化后出现，不能保证每条曲线都在生成途中绘制。只提供文件路径的演示沿用原有读取流程。
