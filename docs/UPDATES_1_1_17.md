# 1.1.17 更新说明

本版适配 Windows x64 官方商店包 `26.915.4065.0`、界面 `26.915.31945` 和内置 Codex 后端 `0.155.0-alpha.9.2`。其他官方版本仍会停止安装，不跳过签名、摘要或权限检查。

## 安装与恢复

下载发行版 ZIP 并解压，保存未发送内容后退出桌面端，双击“安装修复.cmd”。安装会生成独立运行副本，保留现有账号、聊天、模型偏好及恢复备份。使用“卸载恢复.cmd”可撤销本项目的安装。无需另外安装 Python 或 Node.js；附件 SHA256SUMS.txt 用于核对下载文件。

## 本次修正

- 按新版模块与接口重新适配侧聊、正式历史、模型预览、搜索、下载、消息列表和可视化预览。
- 侧聊使用新版面板管理器与激活参数，避免已创建标签却没有激活内容。
- 模型相关性能缓存覆盖新增临床搜索与引用开关，避免保留过时配置。
- 草稿检查点接入新版显式刷新入口；保留官方已有的写入合并机制，并覆盖新版两处日志处理入口。
- 更新原生虚拟列表和流式可视化的实际挂载检查。

## 对话加载修正

- 修正 Chat 和云端 Work 页面恢复逻辑的作用域绑定，避免打开对话时读取空对象并进入错误页。
- 联网搜索来源使用新版原生解析器的初始化入口，修复带搜索内容或正在搜索的对话报错。

## 范围与限制

此补丁不替换独立 Codex CLI，也不修改 Codex 命令运行器二进制。后台命令的外层脚本返回，不等于底层进程退出；丢弃 session_id 或不追踪后台搜索仍可能造成资源占用。本版不宣称修复所有子进程回收问题或消除长时间运行中的全部卡顿。

具体检查及真实界面验收范围见 [兼容性与验证](VALIDATION.md)。报告问题时请附官方版本、修复版本、复现步骤，以及是否同时运行搜索或其他高负载任务；不要上传账号资料或私人聊天记录。官方升级后请等待对应适配，不手动放宽版本限制。
