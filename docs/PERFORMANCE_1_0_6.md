# 模型滑块与代码块滚动改进

这些改进已包含在 [1.0.7](PERFORMANCE_1_0_7.md) 中，升级后自动生效，无需额外设置。

## 拖动模型滑块

滑块经过中间档位时只显示预览，松手后应用最终选择，减少长对话中的重复更新。拖回原位或取消拖动不会改变模型；键盘、滚轮和每段对话的选择记忆继续可用。

滑块装饰动画也减少了不必要的绘制，窗口不可见时会暂停。

## 阅读代码块

代码块从初次显示起就保留完整表头和外框。滚到相应位置时，不会再因为“语言名称、复制按钮”突然出现而把内容向下推。

语法高亮仍按需加载；复制、自动换行和原有语言标签保持可用。

这些调整针对滑块和普通代码块。超大历史、复杂图表或后端无响应造成的卡顿，还需要分别处理，见 [已知问题](AUDIT.md)。
