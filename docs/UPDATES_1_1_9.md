# 1.1.9：修复打开对话报错和任务栏关联

适用于 Windows x64、商店包 **26.911.7940.0**，界面 **26.911.61220**。

- 修复 1.1.8 在发送消息后或打开已有对话时进入错误页的问题：消息导航改用明确导入的 React／JSX 运行库，本地对话和阅读位置回调使用正确的原生接口。
- 为桌面版窗口和快捷方式设置一致的任务栏应用标识，恢复固定入口并避免出现 PowerShell 的任务菜单；网页版快捷方式保持独立。
- 针对 Owl 缺少旧 Electron 任务栏接口的情况，使用 Windows 原生窗口属性接口，后台执行且校验窗口所属进程。

下载对应语言的 ZIP、解压，保存未发送内容并退出客户端后运行安装入口。中文版为“安装修复.cmd”，英文版为“Install-Repair.cmd”。安装保留现有资料目录，恢复入口和备份机制不变。

验证包含真实 Chat 和本地 Codex 历史页面、导航组件的实际 React／JSX 入口、滚动回调、任务栏属性和既有回归。修复不会自动重发消息；历史对话验证未发起新的模型回合。校验值见发行附件。
