# 1.0.10 更新说明

这次主要改善长对话的阅读位置。切出去再回来，不该重新找一遍刚才读到哪里；长消息加载出来，也不该把页面突然拉回顶部。

## 回到上次读到的位置

聊天会记住离开时的位置和消息高度。重新打开时，等消息布局准备好再恢复，避免被加载阶段的临时位置覆盖。下方内容变长时，也会尽量保持原来的阅读位置。

## 长消息加载不再打断滚动

最新一条消息会更早参与高度测量，减少滚到下面才发现消息很长、滚动条突然大幅变化的情况。恢复过程中，如果你开始滚动，会立即以你的操作为准，不再把页面拉回旧位置。

阅读位置保存在本机，缓存有数量上限，只记录位置和高度，不保存聊天正文。图片、网页或互动内容后续改变高度时，滚动条仍可能变化。

## 升级

适用于 Windows x64，微软商店包 **OpenAI.Codex 26.901.6511.0**，界面版本 **26.901.51231**。

保存未发送的内容，完全退出 ChatGPT，解压新版安装包并运行 **安装修复.cmd**。已有修复版可直接升级，现有资料和恢复备份保留。
