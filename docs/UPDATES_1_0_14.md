# 1.0.14 release notes

Message navigation now takes less space beside the conversation. In narrow windows, text starts about 32 pixels from the edge. Markers keep their original lengths and end about 4 pixels before the text, including when expanded. In wide windows, the navigation follows the text column.

Hover previews and click-to-jump remain available. This release also includes [message navigation and Side chat editing from 1.0.11](UPDATES_1_0_11.md). Supported app versions and installation steps are unchanged.
