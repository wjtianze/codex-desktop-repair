# 1.1.8：适配 26.911 桌面客户端

适用于 Windows x64、微软商店包 **OpenAI.Codex 26.911.7940.0**，界面版本 **26.911.61220**。旧版或其他版本会停止安装。保存未发送内容、退出修复版后运行“安装修复.cmd”；现有资料目录、登录信息和对话保持原样。

- 重新适配新版拆分后的聊天、侧聊、右侧面板、搜索来源、代码块和模型滑块模块，保留新版原生功能及权限检查。
- 修复启动器继承 `CODEX_CLI_PATH` 时可能混用旧后端的问题。修复版只启动随当前客户端复制的后端，安装和启动时均校验其 SHA-256；不修改系统环境变量和独立 CLI。对应官方问题 [#46155](https://github.com/openai/codex/issues/46155) 中的后端版本混用部分。
- 继续保留侧聊编辑和重新生成、聊天阅读位置、思考与搜索过程、互动演示、草稿保存及侧栏布局修复。新版已原生区分有内容／无内容的思考区，沿用其展开行为。

本版本通过 461 项原生与辅助模块检查。App 内置后端为 `0.155.0-alpha.2.6`；独立 CLI `0.154.0` 另行验证，修复包不会替换它。自动检查和隔离加载不等于所有真实对话、设备或长期运行场景均已验收。

服务器撤销登录、模型容量不足、网络与浏览器策略初始化失败不在上述启动修复范围内。近期官方 issue 的核对结果见 [问题核对记录](ISSUES_2026_09_17.md)。
