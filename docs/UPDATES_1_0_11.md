# 1.0.11 更新说明

长对话里找回之前的问题，现在可以少滚几屏；侧边聊天里想换个问法，也不用重新复制整段内容。

## 消息导航来到更多聊天窗口

Chat、悬浮快速聊天和侧边聊天接入了 Codex 同款消息导航。对话包含至少四条用户消息时，左侧显示导航刻度：悬停可预览问题和对应回复，点击可跳回那条消息。

窄窗口会为导航预留空间。主聊天和侧边聊天各自导航，查找侧边消息时不会把主聊天滚到别处。预览使用已有聊天内容，不会额外请求模型生成。

## 侧边聊天支持编辑和重新生成

已完成轮次可以编辑最后一条用户消息，或在回复下方点击“重新生成”。操作会从所选轮次新建一个侧边聊天分支，再发送修改后的问题或原始问题；原对话保留，方便比较结果。

重新生成保留原消息输入和附件。生成中、只读状态或不支持此操作的历史模式不会开放按钮；连续点击不会重复提交。

侧边聊天仍是临时会话，关闭应用后会消失。需要长期保存的内容，请先另行保存。

## 升级

适用于 Windows x64，微软商店包 **OpenAI.Codex 26.901.6511.0**，界面版本 **26.901.51231**。

保存草稿和需要保留的侧边聊天内容，完全退出 ChatGPT，解压新版后运行 **安装修复.cmd**。已有修复版可直接升级，登录资料、普通聊天和恢复备份保留。

本版包含 [1.0.10 的阅读位置恢复改进](UPDATES_1_0_10.md)。
