# 1.0.7 更新说明

长对话里，最让人难受的往往不是等回复，而是连改个模型、滚几下页面、点一下停止都不顺畅。这次更新继续处理这些日常操作中的卡顿，也减少了输入草稿时不必要的磁盘写入。

## 有哪些改善

- **任务繁忙时，也给“停止”和追加指令留出空间。** 普通后台请求不会再占满所有请求名额，避免控制操作一直排在后面。如果后端已经完全无响应，停止操作仍可能需要等待。
- **保存草稿不再反复重写大文件。** 只修改输入框文字时，改为保存独立的小型草稿文件及备份，减少持续输入时的磁盘负担。其他设置正常保存。
- **长对话的布局更新更平稳。** 合并密集的尺寸变化，减少同一帧里反复调整消息布局和滚动位置。
- **模型滑块拖动时只预览，松手后应用选择。** 不再为经过的每个中间档位反复更新整段会话。
- **代码块表头从一开始就保留位置。** 不再滚到代码块附近才突然多出一行表头，把正在阅读的内容顶开。语法高亮仍按需加载。
- **减少后台装饰动画的消耗。** 窗口不可见时暂停滑块画布绘制，避免重复重建相同尺寸的画布。

## 怎么升级

仅适用于 Windows x64，微软商店包 `OpenAI.Codex 26.901.6511.0`，界面版本 `26.901.51231`。

1. 保存未发送的内容，完全退出 ChatGPT。
2. 解压新版安装包，双击 **安装修复.cmd**。
3. 安装完成后，从开始菜单的 **ChatGPT** 重新打开。

已有修复版可以直接升级。安装会保留现有登录资料、对话和模型偏好，并创建恢复备份。需要撤销时，退出客户端后运行 **卸载恢复.cmd**。

## 需要知道的限制

这次解决的是几条明确的本地性能问题，并不代表所有 Windows 卡顿、超大对话或后端停滞都已解决。为保持停止和追加指令可用，普通请求会少一些同时执行的名额。

如果客户端异常退出，不要手动删除状态目录中的 `.drafts-v1.json` 文件及其备份，它们可能保存着最新草稿。准备退回旧版本时，先保存输入框中的文字，再正常退出。
