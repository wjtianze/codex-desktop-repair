# 已知问题与修复范围

更新于 2026-09-09。本页帮助你判断：遇到的问题是否在当前修复范围内，以及升级后仍可能有哪些限制。

## 1.0.7 已处理

| 问题 | 当前改善 |
| --- | --- |
| 拖动模型滑块时卡顿 | 拖动只预览，松手后应用，减少反复更新会话；装饰动画也更节省资源。 |
| 滚动时，代码块表头突然出现、内容跳动 | 从初次显示就保留表头和外框，语法高亮按需加载。 |
| [后台请求占满队列，停止或追加指令也被堵住 #43525](https://github.com/openai/codex/issues/43525) | 为控制操作保留请求容量。后端自身无响应时，仍不能保证操作立即完成。 |
| [输入草稿反复重写整个状态文件 #43393](https://github.com/openai/codex/issues/43393) | 纯文本草稿变化改为写入独立小文件和备份，减少磁盘写入。 |
| 历史列表频繁调整布局 | 合并密集的尺寸通知，减少重复更新与滚动位置调整。 |
| [提及搜索卡顿 #31065](https://github.com/openai/codex/issues/31065) | 输入稳定后再搜索，取消过时查询；底层已发出的搜索仍可能需要等待。 |
| [浏览器大记录文件反复读取 #38611](https://github.com/openai/codex/issues/38611) | 分批读取并合并重复通知，降低一次性读取大文件的负担。 |

其他已包含的图片显示、输入框恢复、模型记忆、项目设置和演示功能改进见 [README](../README.md)。

## 仍不能保证解决

| 问题 | 当前限制 |
| --- | --- |

## 反馈问题

请附上客户端版本、修复包版本、触发步骤，以及问题发生在新对话还是长对话。截图请遮挡账号和私人内容，不要公开上传完整会话、账户文件或原始日志。

如果升级后出现新问题，可以先正常退出客户端，再运行 **卸载恢复.cmd**。官方客户端更新后，请等待对应适配，不要强行跳过版本检查。
