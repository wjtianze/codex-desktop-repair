# 排查范围与修复依据

核对日期：2026-09-07。目标为 Windows x64 商店包 26.901.6511.0、界面版本 26.901.51231。扫描覆盖安装资源中的 8830 个条目，其中 7398 个为脚本；脚本匹配和网上反馈只作为排查线索。

## 已确认并修复

主进程与界面进程都曾为短标题解析整段历史预览。主进程还会提前计算未被采用的候选标题。实际处理器采样把主要阻塞定位到这条调用链。现在采用已有名称优先、预览解析上限与有限缓存；完整正文仍由正常渲染流程处理。

其他确认项包括性能采样记录累积、空监听表残留、未落实的闲置历史容量目标、浏览器整文件读取和通知排队、可选设备初始化失败后的清理异常、连续渲染器崩溃恢复循环，以及窗口恢复的异常尺寸。相关保护均使用原版本提取的方法或合成边界数据进行测试。

输入框问题在实际客户端复现：私有对话已经有本地状态，但相应查询缓存了 404，导致输入框被卸载。对同一个查询做只读重取后，输入框立即恢复。补丁保留这种短暂状态下的输入框，进行有限重试；仍遵守原有提交和访问检查。用户已确认恢复正常。网页版短暂消失来自用户观察，未直接确认其内部根因。
