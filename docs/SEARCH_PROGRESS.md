# 生成中的联网搜索

版本：1.0.5。日期：2026-09-08。

普通 Chat 对话的思考区原先会跳过联网搜索记录。现在收到记录时即可显示原生搜索状态和搜索词，来源数据到达后展示网站标签，并可展开查看网页标题与链接。

只展示服务端提供的记录。搜索结果不等同于模型逐页阅读过，尚未收到来源时不显示虚构的网站数量。点击来源才调用原生链接打开入口；受限内容保留原有访问限制。手动收起状态和服务端隐藏指令继续有效，Work 专用活动流程保持原样。

检查覆盖实际思考组件的生成中展开、来源更新后保留收起状态、受限链接、来源去重及不安全地址、没有来源时的显示，以及显式打开网页的动作。两种语言均包含在 326 项检查中。搜索显示已完成本地原生组件验证，没有为验收额外发送在线搜索或模型请求。
