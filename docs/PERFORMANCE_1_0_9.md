# 1.0.9 更新说明

这次把几个“切换模式就用不了”的地方补齐了，也继续处理长对话中的滑块卡顿和代码块跳动。

## 右侧栏，不用再来回切模式

ChatGPT 的聊天模式也有右侧栏入口。聊天、工作、新对话和已有对话中，都可以从右侧栏打开浏览器、文件和侧边聊天。

- **浏览器**：直接打开新标签页。
- **文件**：有本地工作目录时打开文件树；没有工作目录时，可以从本机选择文件并在右侧查看。
- **侧边聊天**：已有本地对话时保留原来的侧聊方式；没有本地对话时，新建独立的临时聊天，不必先开一个 Codex 任务。

这些入口仍遵守账号和工作区的原有权限。侧边聊天是临时的，重要内容请另行保存。

## 拖模型滑块时，文字也跟着变

滑块上方的模型名称和思考档位会实时显示当前预览，不用等松手才知道选到了哪里。松手后才保存选择，保留长对话下减少重复更新的优化。

## 补齐 Chat 对话中的代码块修复

ChatGPT 对话中的普通代码块从初次显示起就保留完整表头，避免滚动到附近才补上表头、把阅读位置顶开。语法高亮仍按需加载。

## 同时包含的性能改善

输入草稿时减少大文件写入；为停止和追加指令保留请求容量；合并长对话中密集的布局更新。详细说明见 [性能改进](PERFORMANCE_1_0_7.md)。这些调整不代表所有后端停滞或整机卡顿都已解决，见 [已知问题](AUDIT.md)。

## 升级

适用于 Windows x64，微软商店包 `OpenAI.Codex 26.901.6511.0`，界面版本 `26.901.51231`。

保存未发送的内容并完全退出 ChatGPT，解压新版安装包，双击 **安装修复.cmd**。安装保留现有资料和恢复备份；完成后从开始菜单重新打开 ChatGPT。
