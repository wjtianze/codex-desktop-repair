# 分栏拖动与开关优化

拖动分隔条时，同一画面帧内的多次指针移动合并为最新宽度。主聊天和右侧面板仍在拖动过程中按帧更新布局，不使用截图、空白占位或松手后才排版的方式。

松手时立即应用最终坐标，并取消尚未执行的旧帧，防止宽度回跳。保留原生宽度上下限、缩放换算、四个方向、键盘调整、双击恢复和取消拖动行为。组件清理时取消待执行更新。

开关右侧面板使用原生的即时布局路径，省去宽度动画期间的连续正文排版。打开时直接显示最终宽度，关闭时正文直接铺开；保留全宽恢复及原生关闭保护。

原生函数回归覆盖高频移动合并、松手前更新、最终位置、清理、缩放和各方向、宽度限制及键盘与双击。此验证不能代替实际长对话拖动的流畅度验收；尚未确认导航布局重复测量的额外开销已经消除。
